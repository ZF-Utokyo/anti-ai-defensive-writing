# Tables and formatting

Use these rules for tables, captions, emphasis, and presentation cleanup.

## Tables

A table should make a comparison easier to read. Include a column only when the
reader needs it to interpret or compare the reported result.

- Preserve supplied values exactly.
- Do not add confidence intervals, significance markers, ranks, arrows, color scales,
  composite metrics, or statistical tests unless they are supplied or required.
- Put units in headers when possible instead of repeating them in each cell.
- Define abbreviations and nonstandard metrics in the caption or nearby text.
- Use consistent precision when the underlying measurements justify it. Do not add
  decimal places that were not measured or supplied.
- Keep the primary comparison visually available without filling cells with prose.
- Put necessary uncertainty beside the estimate or in a clearly labeled column.
  Do not hide valid uncertainty merely to make the table cleaner.
- Do not bold every best value when the comparison is obvious or when bold has no
  stated meaning. If emphasis is used, explain it once.

When an existing interval or metric is unclear, flag its definition or source. Do
not assume that an unfamiliar item is invalid, and do not invent an explanation.

## Captions

A caption should identify what is measured, the evaluated setting, and any notation
needed to read the display. It should not become a second discussion section.

Remove generic claims such as "demonstrating the remarkable robustness of our
comprehensive framework" unless the display directly supports and defines them.

## Em dashes, italics, and bold

- Do not introduce em dashes by default. Replace ornamental uses with ordinary
  sentence boundaries or punctuation.
- Preserve exact quotations and user-requested style.
- Use italics for a real convention, such as a mathematical variable, biological
  name, work title, or venue style requirement. Do not italicize ordinary terms to
  make them look newly defined.
- Use bold for navigation or explicitly defined table emphasis, not as a substitute
  for sentence-level clarity.

## Parentheses and footnotes

Keep a parenthetical only when it supplies compact information at the point of use.
Move a full argument into a sentence. Do not create footnotes for caveats that can be
handled by an exact scope statement in the main text.

## Formatting fidelity

Respect the requested output format, LaTeX commands, citation syntax, and venue
template. Clean prose inside the format without redesigning the document unless the
user requests redesign.
